## Data safety section

When Play asks "Does your app collect or share user data?" → **Yes**.

Then declare these:

**Personal info collected:**
- Name (required, for account)
- Email (required, for login)
- Phone number (optional, for employee portal)
- User IDs (required, internal)

**Financial info collected:**
- Other financial info (payroll/salary data the user themselves enters)

**App activity collected:**
- App interactions (basic analytics via Vercel)

**Encrypted in transit?** → **Yes** (HTTPS everywhere)
**Can users request data deletion?** → **Yes** (via email to support)
